## 项目概述
本目录用于沉淀 JavaSE 阶段的核心知识，重点是容器、字符串、集合体系、匿名内部类、Lambda、Stream、异常、Maven 高级、SpringBoot Web开发基础、统一响应与数据模型、日志框架、全局异常处理、及 MyBatis-Plus 数据库操作。

## 学习建议
- 先掌握 Array/String/StringBuilder，再学 List/Set/Map
- Stream 重点放在 `filter/map/collect` 的组合写法
- Maven 先理解坐标、依赖传递和常用插件，多模块用聚合/继承管理
- SpringBoot 重点理解三层架构分工、IOC 与 DI 的概念和注解使用
- 统一响应 Result、VO/DTO/POJO 三层模型、日期格式化注解是接口开发必用
- MyBatis-Plus 先跑通快速入门（Mapper 继承 BaseMapper + selectList），再学 Wrapper 条件查询和分页
- 日志框架 Logback 用 @Slf4j 注解获取日志对象，配置 logback.xml 控制输出和持久化
- 全局异常处理用 @RestControllerAdvice + @ExceptionHandler 统一捕获异常并返回 Result
