## 项目概述
本目录用于沉淀 JavaSE 阶段的核心知识，重点是容器、字符串、集合体系、匿名内部类、Lambda、Stream、异常、Maven 高级、SpringBoot Web开发基础及 MyBatis-Plus 数据库操作。

- [[MyBatisPlus-数据库操作与动态SQL]]

## 学习建议
- 先掌握 Array/String/StringBuilder，再学 List/Set/Map
- Stream 重点放在 `filter/map/collect` 的组合写法
- Maven 先理解坐标、依赖传递和常用插件，多模块用聚合/继承管理
- SpringBoot 重点理解三层架构分工、IOC 与 DI 的概念和注解使用
- MyBatis-Plus 先跑通快速入门（Mapper 继承 BaseMapper + selectList），再学 Wrapper 条件查询和分页
