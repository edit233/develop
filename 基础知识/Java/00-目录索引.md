## 项目概述
本目录用于沉淀 JavaSE 阶段的核心知识，重点是容器、字符串、集合体系、Lambda、Stream、异常、Maven、SpringBoot 全栈开发、MyBatis-Plus 数据库操作与业务层增强。

## 学习建议
- 先掌握 Array/String/StringBuilder，再学 List/Set/Map
- Stream 重点放在 `filter/map/collect` 的组合写法
- Maven 先理解坐标、依赖传递和常用插件，多模块用聚合/继承管理
- SpringBoot 全栈笔记涵盖：三层架构、IOC/DI、请求参数、统一响应、VO/DTO、日期格式化、Logback 日志、全局异常处理、文件上传、IService 业务层增强、自动填充、MD5 密码加密
- MyBatis-Plus 先跑通快速入门（Mapper 继承 BaseMapper + selectList），再学 Wrapper 条件查询和分页
