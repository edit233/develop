## 概述
构建知识库的第三步、第四步：用**向量模型**把切分好的知识片段转为向量（Embeddings），再把向量存入**向量数据库**（Vector Store）并基于相似度检索。本大类覆盖：常见向量模型选型、Ollama/阿里云 Embeddings 用法、InMemoryVectorStore 的增删查、检索参数建议。

## 向量化（Embeddings）
向量化是将文本转换为高维向量的过程。**语义相似的文本在向量空间中距离更近**，这是语义检索的基础。

### 常见开源小规模向量模型
| 模型 | 参数量 | 维度 | 最大长度 | 核心特点 |
|---|---|---|---|---|
| Qwen3-Embedding-0.6B | 0.6B | 1024 | 32K | MTEB 多语言榜 64.34 分，支持 MRL 维度压缩，多语言能力强 |
| jina-embeddings-v5-omni-nano | ~1.0B | 768 | 8K | 全模态（文本/图像/音频/视频/PDF） |
| BGE-M3 | 0.56B | 1024 | 8K | 稠密+稀疏+多向量混合检索，MIT 协议，多语言优秀 |
| all-MiniLM-L6-v2 | ~0.08B | 384 | 512 | 纯英文优化，推理快 |

### 大规模向量模型（性能更强）
| 模型 | 开发方 | 参数量 | 维度 | 特点 |
|---|---|---|---|---|
| Llama-Embed-Nemotron-8B | NVIDIA | 8B | 4096 | MMTEB 排名第 1（截至 2025.10），性能之王 |
| Qwen3-Embedding-8B | 阿里通义 | 8B | 4096 | MMTEB 第 3（70.58 分），开源社区最流行成熟的顶级模型 |
| Gemini Embedding 2 | Google | 未公开 | - | 原生多模态（文本/图像/视频/音频）向量化 |
| OpenAI text-embedding-3-large | OpenAI | - | 3072 | 商业 API 首选，按量付费，适合不想自己部署的团队 |

开源模型可本地部署，也可用模型平台提供的服务。

### Ollama Embeddings
安装依赖：`uv add langchain-ollama`（本地需已安装 Ollama 并拉取模型）。

标准代码：
```python
from langchain_ollama import OllamaEmbeddings

# 初始化向量模型
embeddings = OllamaEmbeddings(
    model="qwen3-embedding:0.6b",  # 性价比高的模型
    dimensions=1024,               # 可选：限制维度以节省存储
)
```

### 阿里云 Embeddings（DashScope）
阿里云百炼提供 `text-embedding-v3`、`text-embedding-v4` 等向量模型，注册并配置 `DASHSCOPE_API_KEY` 即可使用。由 `langchain-community` 提供支持（**该库已不被官方维护，仅做演示**）。

安装依赖：`uv add langchain-community dashscope`

标准代码（向量化 + 余弦相似度衡量）：
```python
from langchain_community.embeddings import DashScopeEmbeddings
from dotenv import load_dotenv

load_dotenv()

# 初始化 DashScopeEmbeddings，只需指定模型名，会自动从 .env 读取 DASHSCOPE_API_KEY
embeddings = DashScopeEmbeddings(
    model="text-embedding-v4"
)

# 向量化单条文本，返回 list[float]
text = "我爱上班"
vector = embeddings.embed_query(text)
print(f"文本: {text}")
print(f"向量维度: {len(vector)}")
print(f"向量前5维: {vector[:5]}")

# 批量向量化（相当于处理多个知识片段），返回 list[list[float]]
texts = ["我要躺平", "我爱工作", "拒绝加班"]
vectors = embeddings.embed_documents(texts)
print(f"\n批量向量化: {len(vectors)} 条, 维度: {len(vectors[0])}")


# ==============衡量相似度===============
import numpy as np

def cosine_similarity(vec1, vec2):
    """余弦相似度函数"""
    dot = np.dot(vec1, vec2)
    return dot / (np.linalg.norm(vec1) * np.linalg.norm(vec2))

# 比较向量相似度
for i, v in enumerate(vectors):
    similarity = cosine_similarity(vector, v)
    print(f"{texts[i]}:", similarity)
```

输出示例：`"我爱上班"` 与 `"我爱工作"` 的相似度最高（约 0.87），说明语义最接近。

## 向量库（Vector Stores）
向量库用于**存储**和**检索**向量化后的文档。LangChain 支持多种向量库：

| 向量库 | 特点 | 适用场景 |
|---|---|---|
| `InMemoryVectorStore` | 内存存储，零配置 | 测试学习 |
| `Chroma` | 轻量级，支持持久化 | 中小规模 |
| `FAISS` | 高性能，支持 GPU | 大规模检索 |
| [[Milvus 基础概念\|Milvus]] | 高性能，支持 GPU | 大规模生产环境（混合检索+重排） |

### VectorStore 统一接口
LangChain 的 `VectorStore` 把向量数据库与 Embedding 模型合并在一起，提供统一调用方式：
- `add_documents`：添加文档（不用自己向量化，只需提供向量模型，自动完成向量化后写入）
- `delete`：根据 id 批量删除文档
- `similarity_search`：基于相似度检索与用户问题有关的文档（自动把问题向量化再去搜索）

### 准备文档 + 初始化
标准代码：
```python
from langchain_text_splitters import MarkdownHeaderTextSplitter
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_ollama import OllamaEmbeddings

# =============1.准备并切分文档================
with open('./resources/评估.md', 'r', encoding='utf-8') as f:
    doc = f.read()

# 按三级标题结构切分
headers_to_split_on = [
    ("#", "h1"),
    ("##", "h2"),
    ("###", "h3"),
]
markdown_splitter = MarkdownHeaderTextSplitter(
    headers_to_split_on,
    strip_headers=False   # 正文中是否去除标题，False：不去除
)
docs = markdown_splitter.split_text(doc)   # list[Document]

# 为每个文档设置 id，便于后续删除
for i, doc in enumerate(docs, start=1):
    doc.id = f'doc_{i}'

# =============2.初始化向量模型===============
ollama_embeddings = OllamaEmbeddings(
    model="qwen3-embedding:0.6b",  # 性价比高的模型
    dimensions=1024,               # 可选：减少维度以节省存储
)

# =============3.初始化向量数据库===============
vector_store = InMemoryVectorStore(embedding=ollama_embeddings)
```

### 添加/删除文档
标准代码：
```python
# 保存文档到向量数据库，返回生成的 id 列表
ids = vector_store.add_documents(docs)
print(ids)

# 删除文档：按 id 批量删除
vector_store.delete(["doc_1", "doc_2"])
```

### 检索文档
常用检索方法：
- `search`：通用搜索方法，支持最多样化的参数
- `similarity_search`：基于相似度的搜索（返回 `list[Document]`）
- `similarity_search_with_score`：相似度搜索并返回得分（返回 `list[tuple[Document, float]]`）

核心参数：
- `query`：查询条件（用户的问题）
- `k`：返回文档最大数量（默认 4）
- `score_threshold`：相似度最低阈值，低于的文档被丢弃
- `filter`：按文档元数据（metadata）筛选

相似度检索（无得分）：
```python
# 用户问题
query = "论语中教育的目的是什么"

# 相似度检索，返回值是 list[Document]
results = vector_store.similarity_search(
    query=query,
    k=5,
)

# 打印结果
for doc in results:
    print(doc.model_dump_json(indent=2))
```

带相似度得分的检索：
```python
# 相似度搜索并返回分数，结果是 list[tuple[Document, float]]
results = vector_store.similarity_search_with_score(
    query,
    k=5,
)

# 遍历结果，doc 是文档，score 是相似度得分
for doc, score in results:
    print(f"==========score: {score}=============")
    print(doc.model_dump_json(indent=2))
```

检索结果示例（Markdown 结构切分后，metadata 会保留所在章节）：
```json
{
  "id": "doc_3",
  "metadata": {
    "h1": "第一章 教育概述",
    "h2": "第一节 中外教育家及其教育思想",
    "h3": "（三）孔子及《论语》主要思想"
  },
  "page_content": "### （三）孔子及《论语》主要思想  ...",
  "type": "Document"
}
```

## 关键参数建议
- **chunk_size**：建议 200~1000，取决于文档类型和模型上下文长度。
- **chunk_overlap**：建议为 chunk_size 的 10%~20%。
- **k（检索数量）**：建议 3~10，太少可能遗漏，太多可能引入噪声。
