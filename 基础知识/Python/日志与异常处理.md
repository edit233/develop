## 概述
日志配置（标准 logging 与 structlog 结构化日志）与业务异常体系（基类 + 模块异常 + 全局处理器）的标准写法。

## 标准 logging 基础配置
标准完整代码：
```python
import logging

logging.basicConfig(
    level=logging.INFO,  # 输出级别：DEBUG / INFO / WARNING / ERROR / CRITICAL
    # asctime=时间戳  levelname=级别  filename=文件名  lineno=行号  message=消息
    format="%(asctime)s - %(levelname)s - [%(filename)s : %(lineno)d] - %(message)s",
)


def get_logger(name: str):
    """按模块名创建 logger，日志自动标识来源模块"""
    return logging.getLogger(name)
```

## structlog 结构化日志
标准完整代码：
```python
import logging
import sys

import structlog


def configure_logging(level: str = "INFO") -> None:
    """配置彩色控制台结构化日志"""
    log_level = getattr(logging, level.strip().upper(), logging.INFO)  # 字符串级别转常量

    # 1. 标准 logging 输出到控制台（structlog 已渲染，无需再格式化）
    root_logger = logging.getLogger()
    root_logger.setLevel(log_level)
    root_logger.handlers.clear()
    handler = logging.StreamHandler(sys.stdout)  # 输出到标准输出
    handler.setFormatter(logging.Formatter("%(message)s"))
    root_logger.addHandler(handler)

    # 2. structlog 处理器链（按顺序执行）
    processors = [
        structlog.contextvars.merge_contextvars,         # 合并上下文变量（如 request_id）
        structlog.stdlib.add_logger_name,                # 附加日志器名
        structlog.stdlib.add_log_level,                  # 附加日志级别
        structlog.processors.TimeStamper(fmt="%Y-%m-%d %H:%M:%S", utc=False),  # 时间戳
        structlog.stdlib.PositionalArgumentsFormatter(),  # 支持 %s 占位符
        structlog.processors.StackInfoRenderer(),        # 渲染 stack_info=True 的堆栈
        structlog.processors.format_exc_info,            # 渲染异常堆栈
        structlog.dev.ConsoleRenderer(colors=True),      # 彩色控制台渲染
    ]
    structlog.configure(
        processors=processors,
        wrapper_class=structlog.stdlib.BoundLogger,   # 绑定日志器
        logger_factory=structlog.stdlib.LoggerFactory(),  # 复用标准 logging 底层
        cache_logger_on_first_use=True,
    )

    # 3. 压制第三方库日志噪音（非 DEBUG 时不刷屏）
    logging.getLogger("sqlalchemy.engine").setLevel(
        logging.INFO if log_level == logging.DEBUG else logging.WARNING
    )
    logging.getLogger("httpx").setLevel(logging.WARNING)
    logging.getLogger("httpcore").setLevel(logging.WARNING)


def get_logger(name: str) -> structlog.stdlib.BoundLogger:
    """获取 structlog 日志器：logger.info("消息", 键=值)"""
    return structlog.get_logger(name)
```

## 业务异常体系
标准完整代码：
```python
# 1. 业务异常基类（core/exceptions.py）
class ApplicationError(Exception):
    """业务异常基类：所有业务失败统一继承"""
    status_code: int = 500          # HTTP 状态码（子类覆盖）
    code: str = "APPLICATION_ERROR" # 业务错误码（前端据此精确分支）
    message: str = "服务器内部错误"  # 用户提示语


# 2. 模块级具体异常（继承基类，类属性即配置，无需传参）
class 资源NotFoundError(ApplicationError):
    """资源不存在或不属于当前用户"""
    status_code = 400
    code = "RESOURCE_NOT_FOUND"
    message = "资源不存在或不属于当前用户"


# 3. 全局异常处理器：业务异常 → 统一 JSON 响应（main.py 中注册）
from fastapi import FastAPI, Request
from fastapi.responses import JSONResponse

app = FastAPI()


@app.exception_handler(ApplicationError)
async def application_error_handler(request: Request, exc: ApplicationError):
    return JSONResponse(
        status_code=exc.status_code,
        content={"code": exc.code, "message": exc.message},
    )


# 使用：业务层直接 raise 资源NotFoundError（无需实例化参数）
# if 对象 is None:
#     raise 资源NotFoundError
```
